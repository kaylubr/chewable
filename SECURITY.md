# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in my app, please report it privately rather than opening a public GitHub issue.

Email security reports to: `kbreyes.dev@gmail.com`

Please include a description of the vulnerability, steps to reproduce it, and any relevant details that can help me investigate the issue.

I will review legitimate reports and work toward addressing confirmed vulnerabilities as soon as reasonably possible.

## Supported Versions

Security fixes are currently provided only for the latest version of the project.
